#E-Commerce Web Application
A full-stack E-commerce website developed using HTML, CSS, JavaScript, Python (Flask), and MongoDB.
Features
User Login & Signup
Product Categories
Product Search
Add to Cart & Wishlist
Size Selection
Responsive Design
#Technologies Used
HTML
CSS
JavaScript
Python (Flask)
MongoDB
#How to Run
Install Python and MongoDB
Run app.py
Open browser at http://127.0.0.1:5000/
